# West Marches Bardos Campaign Stuff

A custom Foundry VTT module designed for West Marches campaign assets, compendiums, and configurations.

## Features
- Custom compendium packs for campaign entities (Actors, Items, Journals, and Scenes).
- Tailored for Foundry VTT v14 and D&D 5e.

## Installation
1. Clone or download this repository into your Foundry VTT user data directory under `Data/modules/west-marches-bardos`.
2. Ensure the folder name matches `west-marches-bardos`.
3. Launch Foundry VTT, navigate to the **Add-on Modules** tab, and verify the module is detected.
4. Enable the module inside your active game world.

## Manifest URL
  [manifest](https://raw.githubusercontent.com/Serelith-Varn/west-marches-bardos/main/module.json)

## 🔍 Usage

Once enabled:

- Go to the **Compendium** tab
- Look for `Casino Heist – NPCs`
- Drag and drop NPCs into your Actor Directory
